# Neti_Retro

See veebileht on saanud inspiratsiooni neti.ee keskkonnast. Eesmärk on luua veebibrauseri peamine leht millel on kõik vajalikud kiirlingid olemas ühele Tartu Ülikooli tudengile.

Rühmatöö peamised probleemid on tööjaotus, ning ka rühmakaaslasega kontakti loomine.

Hetkel on rühmatöö plaanis kujutatud käitumisnormid aktuaalsed rühmatöö probleemidega.
